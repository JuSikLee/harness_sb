# 검색 결과

질문: 배우자 출산휴가는 며칠이야?

## 핵심 답변
배우자 출산휴가는 유급 10일이며, 자녀 출생일로부터 90일 이내에 사용해야 합니다 [hr/출산휴가_육아휴직_정책.docx · 제2조 (배우자 출산휴가)]. 분할 사용은 1회까지 가능하여 예를 들어 5일+5일로 나눠 쓸 수 있습니다 [hr/출산휴가_육아휴직_정책.docx · 제2조 (배우자 출산휴가)]. 신청은 사내 HR 시스템에서 하며 가족관계증명서 또는 출생증명서 사본을 첨부해야 합니다 [hr/출산휴가_육아휴직_정책.docx · 제2조 (배우자 출산휴가)].
