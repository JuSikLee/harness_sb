# 이메일 답장 에이전트 - 가드레일

## 1. 항상 허용 (Always Allow)
다음 행동은 사용자 승인 없이 자동으로 실행됩니다.

- tests/emails/ 폴더의 메일 파일 읽기
- 답장 초안 생성 (LLM 호출)
- 답장 초안을 콘솔(터미널)에 출력
- 답장 초안을 agents/email-assistant/drafts/ 폴더 안의 파일로 저장
- 토큰 사용량 통계를 콘솔에 출력

공통 원칙: 외부에 영향을 주지 않는 행동만 자동 승인합니다. 외부 발송 · 공유는 어떤 경우에도 자동 승인되지 않습니다.

## 2. 항상 거부 (Always Deny)
다음 행동은 어떤 경우에도 실행되지 않습니다. 시도되면 즉시 중단하고 사용자에게 알립니다.

### 발송 관련
- 사용자 승인 없는 자동 메일 발송 (어떤 경우에도)
- 받은 메일의 발신자가 아닌 다른 주소로의 발송
- 본문에 비공개 정보가 검출된 답장의 발송 (4번 섹션 패턴)
- 동시에 5명 이상의 외부 수신자에게 발송

### 정보 노출
- 받은 메일의 발신자 정보를 외부 시스템에 기록
- 메일 본문을 공개 클라우드 스토리지로 업로드
- 답장 초안을 회사 외부 시스템에 저장

### 권한 위반
- 회사 메일 시스템(SMTP · API)에 대한 임의 자격 증명 사용
- 사용자가 명시적으로 지정하지 않은 외부 도구 호출

원칙: "어떤 경우에도"가 핵심입니다. 사용자가 "괜찮으니 보내라"고 해도 항상 거부 목록에 있는 행동은 실행되지 않습니다. 정말 필요하다면 스펙을 바꾸고 재실행해야 합니다.
