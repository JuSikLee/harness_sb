# 데이터 분석 에이전터 - 재시도 정책

## 1. 검증 항목 (무엇을 검사할 것인가)
결과가 다음 모든 조건을 만족해야 합니다.

### 형식 검증 (결정론적, 코드로)
- 결과 JSON에 다음 필드가 모두 있는가: department, period, total_revenue, by_region, comparison_basis
- comparison_basis 값이 "전월 대비" 또는 "전년 동월 대비" 둘 중 하나인가
- by_region 배열의 각 항목에 region, revenue 두 필드가 있는가
- total_revenue가 by_region의 revenue 합과 일치하는가 (오차 1% 이내)

### 일관성 검증 (분석 흐름 중)
- 모든 부서의 comparison_basis 값이 동일한가 (한 분석 작업 내에서 기준이 통일됐는가)
- 처리한 파일 수와 입력 파일 수가 같은가 (누락된 파일이 없는가)

### 의미 검증 (LLM 평가자)
- 결과 요약에 부서별 매출 차이의 핵심 원인이 1개 이상 적혔는가
- 결과에 원본 데이터에 없는 가상의 수차가 들어가지 않았는가

## 2. 재시도 트리거 (어떤 실패에 재시도할 것인가)

### 재시도 (다시 시도하면 풀릴 가능성이 있음)

- 형식 검증의 어떤 항목이라도 실패
- comparison_basis 값이 다른 부서와 다름 (한 작업 내 일관성 불일치)
- by_region의 revenue 합이 total_revenue와 1% 이상 차이
- 모델이 분석 기준을 자기 판단으로 바꿈
- 일시적 네트워크 오류·도구 호출 실패

### 재시도 안 함 (재시도해도 안 풀림)

- 입력 파일 자체가 손상됨 (.CSV 확장자지만 CSV 형식이 아닌 경우)
- 입력 파일의 인코딩이 깨짐
- 회사 내부에서 약속한 컬럼명이 입력 파일에 아예 없음
- 데이터 자체가 피어 있음

### 처리 방법
- 재시도 가능: 진단 메시지와 함께 재시도 (다음 섹션 참조)
- 재시도 불가: 그 파일만 실패 목록에 추가하고 다른 파일 처리는 계속

## 3. 진단 메시지 (재시도 시 모델에 무엇을 알려줄 것인가)
재시도 시 모델에 다음 형식의 진단 메시지를 추가로 보냅니다.

```
[이전 시도 검증 실패]
파일: {파일 경로}
문제 항목:
- {구체적 항목}

다음 사항을 반드시 반영해 다시 분석해주세요.
- {수정 지침}
```

### 예시 1 (분석 기준 불일치)

[이전 시도 검증 실패]
파일: tests/data/sales_b.csv
문제 항목:
- comparison_basis가 "전년 동월 대비"로 나옴
- 다른 부서들은 "전월 대비"로 분석됐음

다음 사항을 반드시 반영해 다시 분석해주세요.
- 이 파일도 "전월 대비"로 분석할 것
- 영문 컬럼명(last_month)을 한국어 분석 기준에 매핑해서 사용

### 예시 2 (총합 불일치)

[이전 시도 검증 실패]
파일: tests/data/sales_c.csv
문제 항목:
- by_region의 revenue 합: 1,250,000원
- 결과의 total_revenue: 1,300,000원
- 차이: 50,000원 (4% 불일치)

다음 사항을 반드시 반영해 다시 분석해주세요.
- 결측값 행을 어떻게 처리했는지 명시
- 결측값 빼고 계산했다면 total_revenue도 그에 맞춰 갱신

핵심 원칙: "오류"라고만 적지 말고, "어떻게 고칠 것인가"까지 구체적으로.

## 4. 에스컬레이션 (몇 번 실패하면 멈출 것인가)
### 파일별 시도 한도
- 한 파일당 최대 3회 시도(최초 1회 + 재시도 2회)
- 4번째 시도는 하지 않고 해당 파일을 실패 목록(failed_files)에 추가
- 다른 파일 처리는 계속 진행

### 전체 작업 한도
- 입력 파일의 50% 이상이 실패하면 전체 작업 중단 (data quality 문제 의심)
- 누적 토큰 사용량이 200,000을 넘으면 즉시 중단 (비용 폭발 방지)

### 한도 도달 시 처리
- 콘솔에 다음 형식으로 보고:
  ```
  [작업 완료]
  성공: 5건
  실패: 2건
  - tests/data/sales_d.csv: 양식 불일치 (재시도 안 함)
  - tests/data/sales_x.csv: 3회 재시도 후 실패

  성공한 부서로 분석 결과를 작성합니다.
  ```
- 성공 부분은 정상 분석 보고서로 작성
- 실패한 파일 목록은 사용자에게 별도 안내
