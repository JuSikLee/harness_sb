# 회의록 양식 정리 Skill

## 작업 단계

1. **입력 분석**: 회의록 텍스트의 형태(채팅 로그·녹취·노트)를 파악한다.
2. **발언자 정규화**: "김 부장" · "Kim PM" · "@kim" 같은 다양한 표기를 한 가지 형태로 통일한다. 한국어 표기로 통일하는 경우 "성 + 직책"(예: "김 부장"), 영어 표기로 통일하는 경우 "성 + 직책 약어"(예: "Kim PM"). 영어 · 한국어 혼용 금지.
3. **약어 풀이**: references/abbreviation_dict.md를 참조해 모든 약어·코드네임을 처음 등장 시 풀어쓴다.
4. **양식 매핑**: 표준 4섹션으로 정리한다.
   - 안건: 회의에서 실제로 다룬 핵심 주제(개수 제한 없음)
   - 결정: 명확히 결정된 항목
   - 액션 아이템: 담당자·마감일 명시 (모호하면 별표 ★)
   - 다음 회의: 예정 일정·아젠다
5. **검증**: 액션 아이템 담당자가 비어 있는지 · 마감일이 모호한지 확인하고 별표.

## 출력 형식

반드시 마크다운 형식. 4섹션 헤더는 ##. 액션 아이템은 표 형태(담당자 | 할일 | 마감일 | 상태). 각 섹션은 정확히 한 번만 출력한다 --- 같은 섹션 헤더를 두 번 이상 등장시키지 않는다. "★사용시 확인 요청 항목" 같은 별도 섹션을 만들지 않는다.
