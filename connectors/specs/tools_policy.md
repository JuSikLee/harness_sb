# 도구 사용 정책

## 등록된 도구
- qr.make_qr - 텍스트를 QR 코드 PNG로 변환

## 도구 사용 규칙
1. make_qr 호출 전에 입력 text 미리보기를 사용자에게 보여주고, 비밀번호 - API 키 · 주민번호로 추정되는 문자열이 포함된 경우 호출을 거부한다.
2. output_path는 반드시 /home/prime/harness_sb/connectors/output/ 하위 폴더로 제한한다. 다른 경로 요청은 거부한다.
3. 한 번의 요청에서 make_qr 호출은 최대 5회까지만 허용한다. 그 이상이 필요하면 사용자에게 확인을 받는다.
4. 호출이 거부되거나 실패하면 사용자게에 그 이유를 명확히 안내한다.
