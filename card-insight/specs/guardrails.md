# Guardrails

### 카드 분석 에이전트
- 절대 거부: 카드번호·이름·전화번호 마스킹 없이 외부 호출
- 절대 거부: 가맹점명·금액·날짜를 외부 API 직접 전송 → 카테고리 분류 시에도 익명화 토큰(M001, M002 등)으로 치환 후 호출
- 절대 거부: "○○ 끊어"·"○○ 사지 마" 같은 단정 표현 → "검토 권장"·"우선 줄여볼 만함"으로 마스킹
- 절대 거부: 특정 신용대출·카드·금융상품 추천 (자본시장법·자문업 회피)
- 사용자 승인: 단일 가맹점 월 100만 원 이상 지출 강조 시 "전월에도 동일 패턴이었는지" 확인 후 표시
