### 사내 문서 검색 가드레일
- 비공개 정보 분류 (faq/glossary.docx의 C1·C2 정의 참조)
- C1 (최고 기밀): 회사 매출 · 계약 금약 · 임원 의사결정 → 즉시 차단
- C2: 고객 데이터 · 코드네임 · 미공개 제품 계획 → 마스킹
- Internal: 사내 정책 · 매뉴얼 → 답변 가능
- Public: 외부 공개 자료 → 자유

### 비공개 분류 검사 시점 (필수)
- C1 · C2 분류 검사는 반드시 검색 · 임베딩 "이전"(입력 단계)에서 수행한다.
- C1 판정 시 searcher.search()를 호출하지 않고 즉시 거부 메시지 반환
  (검색 · rerank · answerer · Claude 호출 금지). 비공개 내용이 임베딩 · LLM 컨텍스트 · 로그에 들어 가면 안 된다.
- C2 판정 시 검색은 진행하되 출력 직전 코드네임을 [프로젝트 X]로 마스킹한다.
- 한 질문에 C1 · C2가 동시에 걸리면 더 강한 등급(C1=차단)을 우선 적용한다.

### 분류 트리거 (입력 질문 기준)
- C1 키워드: "매출"(단독 포함), 매출액, 영업이익, 계약 금액, 계약금액, 임원 연봉, 급여 총액, 임원 의사결정
- C2 키워드: 코드네임, 코드명, 미공개 제품, 미공개 제품 계획
- C2 정규식(분류에도 사용): (프로젝트|project)\s*[-_]?\s*[A-Za-z가-힣0-9]{1,12} (예: "프로젝트알파")

### 거부 메시지 형식 (C1 차단 시 출력)
"이 질문은 비공개 정보(C1)를 포함합니다.
검색 에이전트는 답을 보여드릴 수 없습니다.
담당자: HR(hr@novatech.example) 또는 분부장에게 직접 문의해주시면 됩니다."

### 로그 · 외부 공유
- C1 차단 시 질문 원문을 캐시 · 로그에 평문 저장하지 않는다(해시만).
- 외부 공유 형태(메일· 메시지)에 C1 직접 노출 금지.
