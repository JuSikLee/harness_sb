# 자산 진단 + 노후 계획 에이전트 - 기술 아키텍처 (필수 규칙)
## 1. 계산 원칙 (절대 규칙)
- 모든 수치 계산은 파이썬 코드로만. LLM에게 산수·복리 계산·합계 검증시키지 않음.
- LLM은 (a) 자연어 → 구조화 데이터 파싱, (b) 결과 텍스트 해설만 담당.
- 외부 거래 API 호출 코드 작성 금지 (증권사·은행·연금공단 API 모두 차단)

## 2. 입력 파싱 (profile_loader.py)
- 자연어 요청을 클로드 API로 파싱:
  · age (현재 나이) / retirement_age (은퇴 목표 나이)
  · current_assets (자산 분포 dict - 주식·예금·부동산·연금 등 자산군별 금액)
  · monthly_income / monthly_expense / monthly_savable
  · retirement_monthly_expense (노후 월 지출 목표, 현재 가치)
  · risk_tolerance (보수·중립·공격, 미입력 시 중립)
- 누락 항목은 memory/financial/long_term/profile.md의 최근 프로필 값으로 먼저 보충한다 ("같은 조건인데 ~만 바꾸면" 형태의 후속 요청 대응). 저장된 프로필도 없으면 기본값 사용 또는 사용자에게 할 질문
- 요청을 처리한 뒤에는 파싱된 프로필을 profile.md에 저장·갱신한다 (memory_policy.md 규칙 적용)

## 3. 가정값 (architecture.md 명시·고정)
- 물가상승률: 연 2.5%
- 자산군별 기대수익률 (연):
  · 국내 주식 6.0% / 해외 주식 7.0% / 국내 채권 4.0% / 해외 채권 4.5%
  · 현금성 자산 2.5% / 부동산 3.0% (인플레이션 헤지 가정) / 대체투자 5.0%
- 노후 기대 생존 기간: 30년 (60세 은퇴 가정 시 90세까지)
- 환경변수 ASSUMPTION_PROFILE로 보수/표준/낙관 3종 전환 가능

## 4. 포트폴리오 분석 (portfolio_analyzer.py)
- 위험 성향 x 나이(은퇴까지 기간) 기반 자산군 권장 비중 산출
  · 보수: 주식 30% / 채권 50% / 현금 10% / 대체 10%
  · 중립: 주식 40% / 채권 30% / 현금 10% / 대체 20%
  · 공격: 주식 60% / 채권 15% / 현금 5% / 대체 20%
  · 은퇴까지 5년 미만이면 자동으로 보수 쪽으로 보정 (-10% 주식, +10% 채권)
- 주식 배분: 국내 60% / 해외 40% (글로벌 분산 권장)
- 채권 배분: 국내 70% / 해외 30%, 국공채 60%·회사채 40%(AA 이상)
- 부동산은 "대체" 자산군으로 분류해 비교한다 (기대수익률은 3번 항목의 부동산 3.0% 적용)
- 현재 자산 분포와 비교 → 자산군별 조정 방향(매수·매도) 제시

## 5. 노후 자금 계산 (retirement_calculator.py)
- FV(필요 자금) = 노후 월 지출 x 12 x 노후 기간 x 인플레이션 누적계수
- 예상 자산 = 현재 자산 x (1+가중평균수익률)^은퇴까지년수 + 월저축 x 복리누적계수
- 갭 = FV - 예상 자산
- 부족 시 월 저축 추가액 제안 (또는 은퇴 1~2년 연기 시뮬레이션 옵션)

## 6. 갭·저축 분석 (gap_finder.py)
- 입력: portfolio + retirement 결과
- 출력: 월 저축 권장액 + 자산군별 분배(예: 주식 ETF 120·채권 90·현금 30·연금 60)
- 월 가용 소득 초과 시 "은퇴 연기" / "노후 지출 조정" 시나리오 함께 제시

## 7. 출력 (report_writer.py)
- output/financial-plan/{YYYYMMDD}_plan_{NN}.docx
- python-docx 사용
- 본문 구성 (4개 표 필수):
1. 입력 정보 표 (나이·자산 구성·월수입/지출·목표)
2. 권장 포트폴리오 표 (자산군별 권장 비중·권장 금액·현재 보유·조정 방향)
3. 자산군 내 분류 가이드 (국내/해외, 인덱스/개별, 신용등급 - 일반론만)
4. 월 저축 운영 + 노후 갭 분석 표
- 첫 페이지 "가정값" 섹션 의무 포함 (물가·수익률·기간)
- 첫 줄·마지막 줄 면책 문구 의무
- 절대 금지: 특정 펀드명·종목코드·증권사명·세금 단정 수치

## 8. 의존성 (필수)
- pip install pandas numpy python-docx anthropic

## 9. 자체 검증 체크리스트 (6개 .py 작성 직후 반드시 통과)
1) pip list에 python-docx, anthropic 모두 존재
2) grep -E "키움|Creon|KIS|증권사|order_buy|order_sell" agents/financial-planner/ 결과 0줄 (자동 거래 코드 없음). 이 검사는 클로드 코드가 직접 실행합니다. PowerShell 또는 Terminal에 그대로 붙여넣지 마세요.
3) python main.py --request "자산 5억, 50세, 60세 은퇴, 월소득 700, 월지출 400, 노후 월 300" 실행 시 .docx 정상 생성
4) 생성된 .docx 첫·마지막 줄에 면책 문구 포함 + "가정값" 섹션 존재 + 자산군 합계 100% 검증
5) python main.py --request "KODEX 200 ETF 추천해줘" 또는 "이 자산이면 상속세 얼마 내?" 실행 시 가드레일 차단 (세금·상속세·증여세·양도세 등 모든 세목 단정 요청 차단)
5개 중 하나라도 실패하면 해당 코드 즉시 재작성. 모두 통과해야 다음 단계 진행.
