질문: Python asyncio.gather 사용법은?

## 핵심 답변
`asyncio.gather()`는 여러 코루틴을 동시에 실행하고, 모든 코루틴이 완료될 때까지 기다린 뒤 결과를 리스트로 반환하는 함수입니다. [1][3] 사용법은 `결과 = await asyncio.gather(코루틴1, 코루틴2, ...)` 형태로, 리스트로 전달할 경우 `asyncio.gather(*코루틴_리스트)`처럼 언패킹하여 넣어야 합니다. [1] 에러 처리 시 기본적으로 하나의 태스크에서 예외가 발생하면 즉시 전파되며, `return_exceptions=True` 옵션을 사용하면 예외도 결과로 모아서 반환받을 수 있습니다. [3]
