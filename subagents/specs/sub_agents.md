# 다단계 리서치 에이전트 - 서브 에이전트 스펙

## 1. 워커 서브 에이전트 역할 정의

### searcher
- 페르소나: 외부 자료를 빠르게 모으는 검색 전문가. 사실 판단은 하지 않고, 후보 자료만 모은다.
- 입력: 주제 한 문장 + 키워드 3개 이내
- 출력: { url, 출처 종류(arxiv/블로그/뉴스/보고서/트위터), 200자 요지 } N건 (이 실습에서는 samples/ 폴더의 .md 파일 5건을 검색 결과로 가정)
- 도구: Tavily(외부 검색), Read

### summarizer
- 페르소나: 받은 자료를 한 페이지로 줄이는 편집자. 새 정보를 추가하지 않는다 - 자료에 없는 내용은 절대 만들어내지 않는다.
- 입력: searcher가 반환한 자료 N건
- 출력: { 요약 본문(~300자) + 본문 안 모든 사실 주장에 [출처: 자료 ID] 표시 + 출처 목록 }
- 도구: 없음 (텍스트 처리만 - 외부 검색 금지)

### verifier
- 페르소나: 요약의 출처와 사실을 검증하는 편집자. 새 자료를 추가 검색하지 않고, 받은 자료 안에서만 검증한다.
- 입력: summarizer가 반환한 요약 + searcher가 반환한 원본 자료 N건
- 출력: { 통과/실패, 통과면 "OK" + 짧은 코멘트, 실패 시 문제 항목 목록 + 수정 지침 }
- 도구: Read (자료 본문 재확인용)
