# 검색 결과

질문: MRR이 뭔가요?

## 핵심 답변
MRR은 Monthly Recurring Revenue의 약자로, '월간 반복 매출'을 의미합니다. [glossary.docx · 2. 사업·제품 약어] 노바테크에서 SaaS 사업의 핵심 지표로 활용되며, 연간 단위로 환산한 값이 ARR(MRR × 12)입니다. [glossary.docx · 2. 사업·제품 약어]
